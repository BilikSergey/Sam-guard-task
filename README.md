# Project for testing "SAM GUARD Trend View"

## Setup

- Install Node.JS

- Clone the project 

```bash
git clone https://github.com/BilikSergey/Sam-guard-task.git
```

-Install dependencies:

```bash
npm install
```

-Create a .env file in the root directory with your credentials:

STAGING_EMAIL=your_email@company.com
STAGING_PASSWORD=your_password

-To run the tests run the command below:

```bash
playwright test
```
